    why this mattersEach mode has its own nodes and never borrows the other's: chained the nodes whose names ECH hides, chained-reality the Reality node, which stays unknown at home until it is needed. Only the node the pilot chose is ever dialled, plus two standbys from other domain families that it checks now and then. A family whose nodes keep failing is set aside for a few hours, since one blocking rule takes out a whole family at once, and a node that answers but stalls on a real download - how some networks throttle - counts as failing. When every node of the mode fails, the pilot says so once and leaves switching modes to you. Delays are measured to the node; the distance on to the WireGuard peer is estimated and added when the pilot chooses, so a fast node on the wrong continent does not win. The delays are for a fresh HTTPS request through each node, which crosses to the node's real server several times over - a page already loaded feels one crossing, not four. A plain ping would answer from the CDN edge in front of the node in a few ms and say nothing about the node itself. Events are the pilot's own log: switches, standbys admitted and dropped, families set aside, outages.
    Recently blocked
    Tracker list
    checking
    why this mattersA request the tracker list rejects fails like any other dead connection - a link to a blocked host opens on ERR_SOCKS_CONNECTION_FAILED or "can't be reached", with nothing saying why. That is deliberate: a page cannot tell the rejection from a firewall. This list, read from the sing-box log and checked against the list itself, is where to tell. Only host names are known here, never the full address, so for an email click-tracking link the real destination has to be read out of the link itself, usually after /CL0/, ?url= or similar.

If this sits in your real country while the exit does not, queries are escaping the chain - a leak neither the exit address nor the shell can see. The resolver is anycast, so its apparent location tracks where the query entered the network rather than the operator's head office.
